# 📨 TG Forwarder

Полноценная студия контента для Telegram: автоматический сбор постов из каналов-источников, буфер с ручной модерацией, шаблоны с медиа и inline-кнопками, авто-публикация, отложенный постинг, интеграция с нейросетью (текст + картинки) и веб-панель с метриками.

## 🏗 Архитектура

Проект полностью упакован в **Docker**. Все сервисы (база, бот, сборщик, API, фронтенд) запускаются одной командой и работают изолированно.

│   Collector     │         │   Publisher     │         │      Bot        │
│  (Telethon)     │         │   (aiogram)     │         │   (aiogram)     │
│  Контейнер      │         │  Встроен в API  │         │  Контейнер      │
└────────┬────────┘         └────────┬────────┘         └────────┬────────┘
          │                           │                           │
          └───────────┬───────────────┴───────────┬───────────────┘
                      │                           │
               ┌──────▼──────┐             ┌──────▼──────┐
               │  PostgreSQL │             │    MinIO    │
               │  Контейнер  │             │  Контейнер  │
               └──────┬──────┘             └──────┬──────┘
                      │                           │
          ┌───────────┴───────────┬───────────────┘
          │                       │
   ┌──────▼──────┐         ┌──────▼──────┐

   │  Контейнер  │         │  (Frontend) │

## 📑 Конфигурация страниц

Новые возможности в конфигурации страниц:

- **Навигация** – список ссылок (`nav_links`) с полями `name` и `url`.
- **Контакты** – поля `contact_telegram`, `contact_email`, `contact_whatsapp`.
- **Фон** – цвет фона (`bg_color`).
- **Заголовок** – `hero_title`, `hero_title_color`, `hero_title_size`, `hero_title_weight`, `hero_title_font`.
- **Подзаголовок** – `hero_subtitle`, `hero_subtitle_color`, `hero_subtitle_size`, `hero_subtitle_font`.
- **Возможности** – блоки с `icon`, `title`, `description`.
- **FAQ** – `faq_title`, `faq_items` (вопрос, ответ).

Эти поля используются в админке для настройки контента и автоматически отображаются на сайте.
